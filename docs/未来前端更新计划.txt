一、核心结论
────────────────────────────────────────────────────────
Streamlit 无法 100% 复现参考样式的以下特性:
  - CSS 伪元素 (::before/::after 网格背景、光晕)
  - @keyframes 动画
  - 自定义输入框样式 (数字箭头隐藏、等宽字体)
  - 按钮滑入填充动效
  - 精确的字体加载控制

必须将前端从 Streamlit 迁移到自建 Web 前端。
最务实的路线: FastAPI + 纯 HTML/CSS/JS，后端业务逻辑大量复用。

二、架构变更
────────────────────────────────────────────────────────
当前:  Streamlit (单体, Python 渲染 UI)
目标:  纯 HTML/CSS/JS 前端 ←HTTP/WS→ FastAPI 后端 → 业务逻辑(layers/)

不需要改的部分 (约 60% 代码可直接复用):
  - layers/signals/        — 7 个模型全部不变
  - layers/features/       — 特征工程不变
  - layers/evaluation/     — 评估器不变
  - layers/risk/           — 风控引擎不变
  - layers/backtest/       — 回测引擎不变
  - layers/ensemble/       — 模型融合不变
  - improved_data_engine.py — 数据引擎不变
  - config/                — 所有配置文件不变

需要新建的部分:
  - FastAPI 后端 (约 40 个 API 端点)
  - 12 个 HTML 页面 + 共享组件库
  - WebSocket 实时通道 (训练进度推送)

七、风险与技术难点
────────────────────────────────────────────────────────
难点                      说明                                    缓解方案
────────────────────────────────────────────────────────
训练进度实时推送           RL 和模型训练可能持续数分钟              WebSocket + 进度百分比回调
Plotly 图表迁移            Streamlit 自动处理大小/主题              Plotly.js 手动配置 dark template
Session 状态管理           st.session_state 在纯前端需要重建         前端全局状态对象 + localStorage
大数据传输                 股票数据可能数万行                        分页 + 后端聚合 + 只传需要的数据
K 线图                     Plotly.js Candlestick 需要特定格式        与 Python 版格式一致，直接映射

八、推荐执行路线 (渐进式, 4 阶段)
────────────────────────────────────────────────────────

[第一阶段: 基础骨架] (5 天)
  1. 搭建 FastAPI 项目结构 + CORS + 错误处理
  2. 创建前端 HTML 模板 + 共享组件库 (导航栏/选择器/按钮/卡片/表格)
  3. 实现主页 (app.py → index.html)
     - 股票选择器 + 数据加载
     - K线图 (Plotly.js) + 成交量
     - 指标卡片 (价格/成交量/RSI/AI预测)
     - 技术分析图表 (RSI/MACD)
  4. WebSocket 基础设施

[第二阶段: 数据与预测] (5 天)
  5. 数据管理页面 (1_数据管理.py)
  6. 预测分析页面 (2_预测分析.py)
  7. 系统设置页面 (4_系统设置.py)

[第三阶段: 核心量化] (10 天)
  8. 模型训练页面 (6_模型训练.py) + 多模型并行训练进度
  9. 信号评估页面 (7_信号评估.py)
  10. 风控系统页面 (8_风控系统.py)
  11. 交易执行页面 (9_交易执行.py) + RL 训练 WebSocket

[第四阶段: 交易与实验] (10 天)
  12. RL交易页面 (9_交易执行.py) — 替代原 3_AI交易.py
  13. 短线交易页面 (5_短线交易.py)
  14. 实验管理页面 (10_实验管理.py)
  15. 全流程管线页面 (11_全流程管线.py)
