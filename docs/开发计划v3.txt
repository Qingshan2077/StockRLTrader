# v3 机构级量化研究平台 — 开发计划

## v1 vs v3 差异对比

| 模块 | v1 (已实现) | v3 (目标) |
|------|------------|----------|
| 配置 | dataclass | YAML 文件 |
| 数据格式 | CSV | parquet/feather/CSV + lazy loading |
| 数据切分 | train/val/test | train/val/test + walk-forward |
| 特征工程 | 37个指标 | 37个 + 版本管理 + 因子缓存 |
| Alpha模型 | LightGBM, MLP | +Linear/Ridge/Lasso/XGBoost/LSTM/GRU/TCN/Transformer |
| Alpha输出 | signal_score | signal_score + signal_confidence + ranking |
| Signal Ensemble | 无 | weighted avg / stacking / voting / regime switching |
| Alpha Evaluation | 无 | IC / RankIC / IC decay / SHAP / factor correlation |
| Portfolio Construction | 无 | sigmoid / zscore / mean-variance / risk-parity |
| 风控层 | 7道约束 | 10+ 约束 + 行业暴露 + factor neutrality |
| 成本建模 | 固定费率 | 市场冲击 sqrt 模型 |
| RL 算法 | PPO | PPO + SAC |
| 回测引擎 | bar-based | bar-based + 事件驱动框架 |
| 评估 | 15指标 | 15指标 + attribution (alpha/cost/turnover/risk) |
| 实验管理 | 无 | config versioning / result tracking / checkpoint |
| 在线推理 | 无 | 预留接口 |

---

## 开发阶段总览 (13 个 Phase, ~120 个开发点)

Phase 0: 基础设施重构 (YAML配置 + 日志升级 + 数据层升级)
Phase 1: 特征工程 v2 (版本管理 + 缓存 + 多类型特征)
Phase 2: Alpha 模型库 (8种模型 + 标签系统 v2)
Phase 3: Signal Ensemble (融合框架 + 多策略)
Phase 4: Alpha Evaluation (IC/RankIC/SHAP/因子分析)
Phase 5: Portfolio Construction (权重生成 + 优化器)
Phase 6: Risk & Cost v2 (机构级约束 + 市场冲击模型)
Phase 7: RL Execution v2 (SAC + 多目标奖励 + reward ablation)
Phase 8: Backtest Engine v2 (事件驱动 + 部分成交 + 保证金)
Phase 9: Evaluation & Attribution (归因分析)
Phase 10: Experiment Manager (实验追踪 + 版本管理)
Phase 11: Pipeline Orchestration (walk-forward + 超参搜索)
Phase 12: Multi-Asset Extension (组合优化 + 横截面)
Phase 13: Online Inference (实时推理接口)

## 验证标准（每个 Phase 完成后）

| Phase | 验证标准 |
|-------|---------|
| 0 | python -c "from utils.config_loader import ConfigLoader; c = ConfigLoader()" 无报错 |
| 1 | 特征缓存命中率 > 80%, feature pipeline 生成 50+ 特征 |
| 2 | 每个模型通过 check_base_model_interface 测试, 至少 3 个模型 R^2 > 0 |
| 3 | Ensemble 在验证集上 IC > 单模型均值 |
| 4 | IC t-stat > 2, SHAP 可正常输出 summary plot |
| 5 | 组合优化器在约束条件下无报错, weight sum ~= 1 |
| 6 | 每道约束有独立测试用例, cost model 输出合理值 |
| 7 | check_env(env_v2) 通过, reward ablation 有区分度 |
| 8 | Walk-forward 5 folds 均无报错, 输出完整报告 |
| 9 | 归因分解之和 ~= 总收益, 误差 < 1% |
| 10 | 实验记录可查询, 两个实验可对比 |
| 11 | python run_pipeline.py 从头跑到尾不中断 |
| 12 | 3 只股票同时回测, 协方差矩阵半正定 |
| 13 | 单步推理 < 100ms, API 返回正确格式 |
