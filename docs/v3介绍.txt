      ┌──────────────────────────────────────────────────────────────────┐
      │  第3步: Alpha 信号层 (8种模型可选)                                   │
      │  ─────────────────────────────────                                │
      │  统一接口 BaseAlphaModel: fit / predict / get_importance / save/load │
      │                                                                   │
      │  传统模型:              深度学习模型:                                │
      │    • LightGBM (默认)      • MLP                                    │
      │    • XGBoost              • LSTM (含hidden state配置)               │
      │    • Ridge/Lasso/Linear   • GRU                                    │
      │                           • Temporal CNN (dilated conv)            │
      │                           • Transformer (positional encoding)      │
      │                                                                   │
      │  标签: 回归(未来5日收益) / 分类(涨/跌/震荡) / 排序(截面分位数)            │
      │  切分: 时序 train(60%) / val(20%) / test(20%), 严禁 shuffle          │
      │  输出: signal_score (z-score → tanh 标准化到 [-1,1])                 │
      └──────────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
      ┌──────────────────────────────────────────────────────────────────┐
      │  第4步: Alpha 评估                                                 │
      │  ────────────────                                                  │
      │  • IC (Pearson correlation): 信号与未来收益的相关性                    │
      │  • RankIC (Spearman): 排名相关性, 更鲁棒                              │
      │  • IC decay: 不同预测horizon [1,3,5,10,20]天的IC衰减曲线             │
      │  • 滚动IC序列: IC_mean / IC_std / IC_tstat / IC_IR                │
      │  • 分位数分析: 信号分5档, 计算每档平均收益, Top-Bottom spread         │
      │  • 因子相关性矩阵                                                   │
      │  • 信号换手率                                                      │
      └──────────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
      ┌──────────────────────────────────────────────────────────────────┐
      │  第5步: Signal Ensemble (多模型融合) —— 可选                         │
      │  ────────────────────────────────────────                           │
      │  4种融合策略:                                                       │
      │    • WeightedEnsemble: 按验证集R²动态分配权重                          │
      │    • StackingEnsemble: meta-learner(Ridge)拟合子模型输出              │
      │    • VotingEnsemble: hard/soft投票(分类模式)                         │
      │    • RegimeEnsemble: 不同行情(trend/vol/volume)用不同模型             │
      │                                                                   │
      │  输出: ensemble_score + confidence + model_contributions           │
      └──────────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
      ┌──────────────────────────────────────────────────────────────────┐
      │  第6步: Portfolio Construction (组合构建)                           │
      │  ─────────────────────────────────────────                         │
      │  权重映射 (3种方法):                                                │
      │    • sigmoid: weight = 2*sigmoid(α*score) - 1 → [-1,1]            │
      │    • z-score: (score - μ)/σ → clip to ±1                           │
      │    • rank: 按排名均匀分配 [-1,1]                                    │
      │                                                                   │
      │  组合优化器 (单资产时简化, 多资产时完整):                              │
      │    • Mean-Variance (scipy.optimize SLSQP)                         │
      │    • Risk Parity (equal risk contribution)                        │
      │    • Minimum Variance                                              │
      │                                                                   │
      │  再平衡策略:                                                        │
      │    • Calendar: 固定周期再平衡                                        │
      │    • Threshold: 权重偏离阈值触发                                     │
      └──────────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
      ┌──────────────────────────────────────────────────────────────────┐
      │  第7步: Risk & Cost (机构级风控) —— 独立模块                          │
      │  ─────────────────────────────────────────                          │
      │  RiskEngine 顺序执行7道约束, 每道可独立测试:                           │
      │                                                                   │
      │  1. PositionConstraints  仓位上限/净暴露/单资产上限裁剪                │
      │  2. Stop Loss            固定止损(-5%), 半仓重入                      │
      │  3. VolatilityConstraints Target vol缩放 + 高波降仓(×0.7)            │
      │  4. DrawdownControl      Circuit breaker(-20%) + 动态降仓            │
      │  5. LiquidityConstraints  ADV限制(0.01×ADV) + 最低成交量过滤           │
      │  6. Turnover Limit       单日换手率 ≤ 30%                            │
      │  7. CostModel            手续费+滑点+市场冲击(sqrt模型)                 │
      │                                                                   │
      │  市场冲击: impact = k * sqrt(order_size / ADV), k=0.1               │
      │  输出: adjusted_position + risk_report (每道约束的裁减量)             │
      └──────────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
      ┌──────────────────────────────────────────────────────────────────┐
      │  第8步: RL Execution (强化学习执行优化)                              │
      │  ──────────────────────────────────────                             │
      │  核心思想: RL 不预测涨跌, 只优化"调仓节奏"                              │
      │                                                                   │
      │  ExecutionEnv (Gymnasium):                                        │
      │    状态(~40维): signal_score + target_position + current_position   │
      │                + 波动率/回撤/成本估计 + 滑动窗口历史(5天×4)            │
      │    动作: execution_ratio ∈ [0,1] (连续)                             │
      │    执行: executed = current + ratio × (target - current)           │
      │                                                                   │
      │  奖励 (多目标, 可Ablation):                                         │
      │    reward = pnl - λ₁*cost - λ₂*turnover - λ₃*drawdown - λ₄*vol   │
      │                                                                   │
      │  算法: PPO (默认) / SAC                                             │
      │  Ablation: 逐项去掉reward分量, 对比效果                               │
      │  训练: 100K步, ~3-5分钟                                             │
      └──────────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
      ┌──────────────────────────────────────────────────────────────────┐

      │                                                                   │
      │  事件驱动框架 (扩展):                                                │
      │    MarketEvent → SignalEvent → OrderEvent → FillEvent             │
      │    支持 partial fill / 延迟执行 / 杠杆保证金                          │
      │                                                                   │
      │  Walk-Forward 回测 (可选):                                          │
      │    expanding/rolling window, N folds 独立训练+测试                    │

  期望的三组对比输出

  python run_pipeline.py --ticker AAPL

                 年化收益率         夏普比率         最大回撤          换手率
  signal_only     12.3%            0.85           -18.2%          320%
  signal_risk      9.1%            0.92           -12.5%          180%
  full_layered     8.7%            1.05           -10.8%          120%

  核心验证点：全三层系统（full_layered）虽然收益率可能略低于纯信号，但夏普更高、回撤更小、换手大幅减少——这就是分层架构的
  价值：用更少的交易成本、更低的风险，换取更稳定的风险调整后收益。
