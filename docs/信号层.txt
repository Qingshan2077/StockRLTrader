信号层是怎么实现的

  一句话概括 
 把今天的 40+ 个技术指标塞进模型，让模型输出一个数字——未来 5天预计涨跌多少%。正值看涨，负值看跌，绝对值越大信号越强。                                                                                                                       t
  ---
  一、标签怎么造（模型要学什么）

  标签 y = 未来第 h 天的收盘价 ÷ 今天的收盘价 - 1

  具体代码 (layers/signals/labels/label_factory.py:30)：

  close = df['Close']
  fwd_ret = close.shift(-h) / close - 1    # 把 t+h 天的价格"拉回"第 t 行

  比如今天股价 100，5 天后 103，标签就是 0.03（涨 3%）。模型训练时看到的就是"历史上的今天"的特征 →
  "历史上的未来"的真实收益率。

  ★ Insight ─────────────────────────────────────
  shift(-h) 是关键操作——它把未来数据"拉回"到当前行，构造监督学习的标签。配合特征侧的
  shift(1)（特征只用到昨天的数据），形成严格的时间因果链：只允许"过去→未来"的信息流，绝不允许未来信息泄露到特征中。
  ─────────────────────────────────────────────────

  ---
  二、特征长什么样（模型看到什么）

  6 组共 40+ 个特征列，每列都是一个浮点数时间序列：

  ┌────────┬──────────────────┬───────────────────────────┐
  │ 特征组 │     典型特征     │           含义            │
  ├────────┼──────────────────┼───────────────────────────┤
  │ 趋势   │ dist_sma_20      │ 价格偏离 20 日均线多少 %  │
  ├────────┼──────────────────┼───────────────────────────┤
  │ 动量   │ RSI_14           │ 14 日相对强弱，0~100      │
  ├────────┼──────────────────┼───────────────────────────┤
  │ 波动率 │ vol_20d          │ 年化波动率，如 0.25 = 25% │
  ├────────┼──────────────────┼───────────────────────────┤
  │ 成交量 │ vol_ratio_10     │ 今日量 / 10 日均量        │
  ├────────┼──────────────────┼───────────────────────────┤
  │ 风险   │ dd_20d           │ 20 日内最大回撤           │
  ├────────┼──────────────────┼───────────────────────────┤
  │ 市场   │ regime_composite │ 综合市场状态编码          │
  └────────┴──────────────────┴───────────────────────────┘

  所有特征都做了 shift(1)——T 日的特征只包含 T-1 日及之前的信息，严禁偷看今天的价格。

  ---
  三、模型学到了什么

  输入 X                               输出 ŷ
  ┌──────────────────────┐            ┌──────┐
  │ RSI_14 = 28 (超卖)    │            │      │
  │ dist_sma_20 = -0.04   │   模型 f   │ +0.05│  → 预测未来5天涨5%
  │ vol_20d = 0.35 (偏高) │  ───────→  │      │
  │ MACD 即将金叉          │            │      │
  │ ... (40+ 个特征)       │            │      │
  └──────────────────────┘            └──────┘

  7 种模型学到同一件事，但方式不同：

  树模型（LightGBM / XGBoost）—— 学"条件组合"

  把特征空间切成几百个矩形区域，每个区域给出一个预测值。比如：

  ▎ "如果 RSI < 30 且 价格低于 20 日均线 3% 以上 且 波动率在下降 → 预测 +2.8%"

  每个叶子节点就是一条这样的规则。200 棵树叠加后，形成了覆盖所有特征组合的复杂非线性函数。

  Ridge —— 学"线性权重"

  最简单：每个特征乘一个权重，求和。

  ▎ "RSI 每低 10 点，预期收益 +0.3%；波动率每高 10%，预期收益 -0.5%"

  可解释但表达能力弱。

  MLP —— 学"非线性交互"

  两层全连接网络，可以学到类似 (RSI < 30) AND (dist_sma < -0.03) 这样的特征组合，但不是显式规则，而是隐式的权重矩阵。

  LSTM —— 学"时序演化"

  过去20天的特征轨迹:
  Day1: RSI=50, vol=0.20  ─┐
  Day2: RSI=45, vol=0.22   │
  ...                       ├─→ LSTM → 预测未来收益率
  Day19: RSI=32, vol=0.30  │
  Day20: RSI=28, vol=0.35 ─┘

  LSTM 能看到过程而非单点快照。它学到的是"波动率从低到高攀升 + RSI 连续下滑进入超卖 → 可能即将反弹"这种时序模式。

  Transformer —— 学"任意距离的关联"

  和 LSTM 的输入形状相同（20 天 × 40 特征），但通过多头自注意力直接计算任意两个交易日之间的关联强度：

            Day1  Day5  Day10  Day15  Day20
  Day1      0.8   0.3   0.1    0.05   0.02
  Day5      0.3   0.7   0.4    0.2    0.1
  Day10     0.1   0.4   0.9    0.5    0.3
  Day15     0.05  0.2   0.5    0.8    0.6
  Day20     0.02  0.1   0.3    0.6    1.0   ← 今天和昨天(Day15)关联最强

  这让 Transformer 可以捕捉"10 天前 RSI 跌破 30 → 5 天前金叉 → 今天放量突破"这样的跨时间因果链，而不需要像 LSTM
  那样通过隐状态逐日传递。

  ★ Insight ─────────────────────────────────────
  树模型和深度学习模型在这个问题上的本质区别：
  - 树模型：看到的是"一帧截图"（T 日所有指标的瞬时值），擅长捕捉非线性条件组合
  - LSTM/Transformer：看到的是"一段视频"（过去 20 天的完整轨迹），能捕捉时序演化模式
  - 实践中 LightGBM 在表格数据上往往不输深度学习，因为金融数据的信噪比极低，复杂的时序模型容易过拟合噪声
  ─────────────────────────────────────────────────

  ---
  四、为什么这件事能预测走势

  模型的预测值本质上是历史规律的条件期望：

  $$\hat{y} = \mathbb{E}[\text{未来收益率} \mid \text{当前技术面特征}]$$

  如果历史上类似的技术面状态（超卖 + 缩量止跌 + 波动率回落）之后，大部分时候收益率为正 → 模型就会输出正值 →
  系统解读为看涨信号。

  它不能预测：突发事件（财报、政策、黑天鹅）。

  它能捕捉：技术面中蕴含的概率优势——"这种形态历史上 60% 的时候上涨"，长期按信号交易就能获得正期望。

  五、完整数据流

  OHLCV 原始数据
    │
    ▼ FeaturePipeline.build_features()          [shift(1) 防泄露]
  40+ 个特征列 (n_days × 40)
    │
    ├─→ LabelFactory: y = close.shift(-5)/close - 1   [shift(-5) 拉未来到当前]
    │
    ▼ 时间顺序切分: train(60%) / val(20%) / test(20%)
    │
    ▼ 模型.fit(X_train, y_train, X_val, y_val)
    │
    ▼ 模型.predict(X_test) → 预测值 ŷ
    │
    ▼ AlphaEvaluator: IC = corr(ŷ, y_true)
    │   如果 IC > 0.03  → 信号有效

  你可以在页面 「6. 模型训练」 中一键训练全部 7 种模型，然后在 「7. 信号评估」 中查看 IC / RankIC
  来判断信号是否真的学到了东西。
