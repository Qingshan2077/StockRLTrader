# Independent RL Trading Implementation Plan

> **For agentic workers:** Use subagent-driven-development for isolated implementation and requesting-code-review for the integrated result. Checkboxes track completion.

**Goal:** Deliver an independently runnable RL position decision research project with trustworthy accounting and evaluation.

**Architecture:** New stockrl package owns data, causal observations, a shared Gymnasium account/environment, algorithms, evaluation and artifacts. CLI and Streamlit call the same experiment functions. Remove the obsolete prediction stack after new behavior is verified.

**Tech Stack:** Python 3.12+, NumPy, pandas, Gymnasium, Stable-Baselines3, PyTorch, Streamlit, Plotly, pytest.

**Spec:** ../specs/2026-09-08-rl-core-design.md

## Global Constraints

- Python 3.12+; daily single-asset, long-only, no leverage or shorting.
- Observe close t, execute open t+1, mark close t+1; costs are included in NAV exactly once.
- Action [-1,1] maps to requested portfolio weight [0,1].
- Train/validation/test reward intervals are disjoint; preprocessing fits train only; validation selects checkpoints; test never selects checkpoints.
- Preserve user data; no broker actions, no remote push. Synthetic results must be labelled demonstration.
- One shared TradingEnv for algorithms and baselines. At end of data use truncation and mark-to-market, not fictitious liquidation.

```python
TradingEnv(bars, config=None, start=None, end=None, normalizer=None,
           random_start=False, episode_length=None)
# start is inclusive observation row, first fill is start+1; end is inclusive final mark row.
# reset -> (float32 observation, info); step -> (obs,reward,terminated,truncated,info)

```
