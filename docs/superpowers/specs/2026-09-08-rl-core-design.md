# StockRLTrader 独立 RL 交易实验设计

用户已选择：自主决定买入、卖出和仓位。StockTrader 负责截面选股，本仓库负责独立的序列交易决策。

## 第一版范围

Python 3.12+；日线单资产、只做多、不融资、不做空；PPO 为默认算法，SAC 为对照算法。可以在不同股票上分别实验，不声称已实现多资产组合。RL 观察历史行情和账户状态，直接输出目标仓位，监督学习预测值不是必需输入。CSV 为离线数据入口，提供明确标注的合成数据用于演示及技术验证，Yahoo 下载为可选便利功能。无实盘下单。

## 时序与账户

时刻 t 的观测只能使用截至 t 收盘的行情。动作 a∈[-1,1] 映射为目标仓位 w=(a+1)/2。目标在下一交易行 t+1 的开盘执行，按 t+1 收盘估值，并返回下一观测。隔夜收益由原持仓承担，新买入仓位只承担成交后的收益。交易资金、持股、费用和净值由唯一的 TradingEnv 记账，评估和训练均使用该环境。

买入成本包含方向性滑点和手续费，现金不能透支；卖出收入必须加回现金。支持配置买入整手、最低佣金、卖出税率、最大单次参与率和下一交易日可卖限制。参与率只能使用截至决策日的历史成交量估计，不能读取尚未知的次日全天成交量。无成交量或停牌时不成交，仍推进时间。第一版不声称实现完整 A 股撮合、盘口排队或准确的大额市场冲击；零量停牌、整手及 T+1 不等于完整交易所规则适配。

基础奖励 r=log(V[t+1]/V[t])，V 已扣除真实交易费用，不重复把现金费用扣进奖励。可选惩罚只使用无量纲的新增回撤及实际换手比例，默认权重为零，用消融实验验证。环境真实破产终止；数据尾部或人为时间上限为截断。截断时按市值报告未平仓持仓，不凭空强制成交，也不把截断后继续上涨计入奖励。

## 数据与观察

输入 Date/Open/High/Low/Close/Volume，日期唯一递增，价格有限且正，OHLC 合法，成交量非负。价格口径须一致；CSV 导入的复权、分红及拆股处理由用户在数据来源中说明。观察特征用收益率、区间、开收收益、历史波动率、动量、成交量相对水平；历史滚动特征不读取未来。Warm-up 行只能作为历史上下文，不能跨切分产生奖励。

按日期划分 train/validation/test，三个环境的收益区间不重叠。验证和测试允许读取各自开始前的观察历史，但不能在前一段成交。归一化参数只拟合训练期。每个训练 seed 只在验证期挑选最佳检查点，测试期不参与训练、归一化或检查点选择。至少可以运行三个 seed 并报告各自测试结果与均值/标准差；短烟雾实验只证明软件可运行，不能说明有盈利能力。

## 比较与产物

基准：现金、买入持有、固定半仓、均线择时。基准与 RL 必须使用相同价格、费用、交易约束和评估时间区间。指标：净收益、年化收益、波动、Sharpe（无风险利率默认零并注明）、最大回撤、总换手、费用、平均仓位、交易数；无数据或无波动的指标用 null 表示未定义，不能用零掩盖缺失。结果同时保存原始净值、成交和动作记录，模型、归一化、数据指纹、配置、seed、切分边界及运行版本。

## 工程边界

新代码集中在 stockrl/，去除旧 layers/、utils/、scripts/ 和监督学习/预测页面的活跃代码；原实现留在 Git 历史。保留现有用户行情文件，旧实验数据不作为新 RL 的证据。删除监督学习依赖和宽泛 data/、*.md 忽略规则。README 描述真实实现和研究限制。

Web 界面沿用 Streamlit，主题为实验记录台：深蓝黑 #101820、纸白 #e7edf2、次要灰 #9aa9b8、青绿 #61d3ba、琥珀 #e5b567。标题用 Georgia/Noto Serif SC，正文用 Segoe UI/Microsoft YaHei，数据用 Consolas；不依赖远端字体。核心视觉是同轴的净值与持仓轨迹。页面仅保留数据/环境、训练实验、结果对比，明确区分演示与真实市场数据；不显示未经校准的预测概率或置信区间。

## 验收

资金守恒、下一开盘成交、隔夜收益归属、费用一次扣除、卖出回款、整手/现金/参与率约束、未来行情扰动不改变过去观察、环境 reset/seed、截断语义、训练期归一化、样本外区间、保存加载一致性、PPO/SAC 小步真实训练、基准评估与 CLI、Streamlit 启动均验证。获利不是本次技术验收条件。
