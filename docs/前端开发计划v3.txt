 v3 前端适配计划                                                                                                                                                                pt
 Context

 v3 后端（layers/）已实现 10+ 个独立模块，但目前只能通过命令行（run_pipeline.py）使用。
 需要新增 Streamlit 页面把这些功能可视化，同时保留旧前端 5 个页面不动。

 旧页面继续导入旧模块（improved_data_engine, predictor, macd_strategy），
 新页面导入 v3 模块（layers/）。两套系统通过 session_state 共享股票代码和数据。

 设计原则

 1. 不破坏旧页面 — 所有旧文件只读不改
 2. 复用旧系统 UI 模式 — Streamlit + Plotly，保持一致的视觉风格
 3. 一个页面对应一个功能域 — 每页聚焦一个 v3 模块
 4. 渐进可用 — 没训练过模型的页面也能打开，显示引导提示

 页面详细设计

 页面 6: 模型训练 (6_模型训练.py)

 功能: 选择/训练 Alpha 模型 + 对比 + Ensemble

 左侧栏:
   - 股票选择 (复用旧系统的 stock_data/ 列表)
   - 模型类型多选: LightGBM / XGBoost / Ridge / MLP / LSTM / GRU / TCN / Transformer
   - 标签类型: 回归 / 分类 (下拉)
   - 预测天数 slider: 1/3/5/10/20
   - [训练选中模型] 按钮
   - [训练全部对比] 按钮

 主区域:
   ┌─ 标签1: 训练进度 ──────────────────────┐
   │  训练日志 (实时刷新)                      │
   │  每个模型: 训练时间 / val_R² / val_RMSE    │
   └────────────────────────────────────────┘
   ┌─ 标签2: 模型对比 ──────────────────────┐
   │  柱状图: 各模型 R² / RMSE / 训练时间       │
   │  对比表: 按指标排序                      │
   │  特征重要性图 (LightGBM/XGBoost)          │
   └────────────────────────────────────────┘
   ┌─ 标签3: Ensemble ─────────────────────┐
   │  融合方法选择: 加权/Stacking/Regime       │
   │  [构建Ensemble] 按钮                    │
   │  Ensemble vs 单模型对比                  │
   │  各模型权重饼图 / 贡献比例                │
   └────────────────────────────────────────┘

 调用的 v3 模块:
 - layers.signals.models.* — 8 种模型
 - layers.signals.trainer.ModelTrainer
 - layers.ensemble.EnsembleManager
 - layers.data.data_provider.MarketDataProvider
 - layers.features.FeaturePipeline

 风险

 ┌──────────────────────────────────────────────────────┬────────────────────────────────────────┐
 │                         风险                         │                  缓解                  │
 ├──────────────────────────────────────────────────────┼────────────────────────────────────────┤
 │ Streamlit session_state 跨页面共享模型对象可能内存大 │ 只存路径和指标, 模型按需加载           │
 ├──────────────────────────────────────────────────────┼────────────────────────────────────────┤
 │ RL 训练在 Streamlit 中可能阻塞 UI                    │ 用后台线程 + 轮询进度                  │

 │ 旧系统和新系统数据格式不完全兼容                     │ v3_utils 统一封装数据加载, 屏蔽差异    │
 ├──────────────────────────────────────────────────────┼────────────────────────────────────────┤
 │ yfinance 限流导致前端卡死                            │ 优先用本地缓存, 下载失败时显示明确错误 │
