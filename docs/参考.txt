当前项目如何判断股票走势与可信度                                                         ────────────────────────────

  一、系统预测的是什么                               5s)
                                                                                                                          系统在信号层做的事情：基于历史特征（价格、成交量、RSI、MACD 等），预测未来 N 天的收益率。默认配置是预测未来 5 天。
                                                                                                                          预测值 > 0  →  看涨（未来5天预计上涨）
  预测值 < 0  →  看跌（未来5天预计下跌）

  7 种模型可以干这件事：LightGBM、XGBoost、Ridge、MLP、LSTM、GRU、Transformer。

  ---
  二、判断可信度的核心指标

  ★ Insight ─────────────────────────────────────
  量化交易中评估信号质量的黄金标准是 IC（Information
  Coefficient），即预测值与实际收益的相关系数。这比"准确率"更专业——因为准确率只看方向对不对，IC
  还衡量了"预测的幅度准不准"。
  ─────────────────────────────────────────────────

  ┌───────────────────┬────────────────────────────────────────┬──────────────────────────────────────┐
  │       指标        │                  含义                  │            怎么判断可信用            │
  ├───────────────────┼────────────────────────────────────────┼──────────────────────────────────────┤
  │ IC                │ 预测值与实际收益的 Pearson 相关系数    │ > 0.05 优秀，> 0.03 可用，< 0 不可用 │
  ├───────────────────┼────────────────────────────────────────┼──────────────────────────────────────┤
  │ Rank IC           │ 预测排序与实际收益排序的 Spearman 相关 │ 比 IC 更稳健，阈值同上               │
  ├───────────────────┼────────────────────────────────────────┼──────────────────────────────────────┤
  │ IC t-stat         │ IC 的统计显著性检验                    │ > 2 表示显著（不是随机噪声）         │
  ├───────────────────┼────────────────────────────────────────┼──────────────────────────────────────┤
  │ IC IR             │ IC 均值 / IC 标准差                    │ 衡量 IC 的稳定性，越大越好           │
  ├───────────────────┼────────────────────────────────────────┼──────────────────────────────────────┤
  │ Top-Bottom Spread │ 最高分 vs 最低分组收益差               │ 差的越大，信号区分度越好             │
  └───────────────────┴────────────────────────────────────────┴──────────────────────────────────────┘

  ---
  三、实操：在页面上怎么判断

  方式 1：使用「模型训练」+「信号评估」页面（推荐）

  这是 v3 新系统的正确用法：

  页面 6「模型训练」                    页面 7「信号评估」
       │                                      │
       ├─ 选股票 + 选模型                    ├─ IC / RankIC ← 关键！
       ├─ 点击「训练全部」                   ├─ 滚动 IC 时序图（看是否稳定>0）
       └─ 看到 R² 和 RMSE                    ├─ 分位数分析（Top-Bottom Spread）
                                             └─ 信号分布直方图

  可信的判断标准：
  1. 在信号评估页看 IC 值 — 如果 IC > 0.03 且 t-stat > 2，信号有效
  2. 看滚动 IC 图 — IC 曲线大部分时间在零轴上方，说明预测能力持续存在
  3. 看分位数柱状图 — Q5（最强信号组）明显高于 Q1 组

  方式 2：使用旧的「预测分析」页面

  页面 2 用的是旧版 AdvancedPredictor（XGBoost），输出的是涨跌概率：
  - 概率 > 55% → 看涨
  - 概率 < 45% → 看跌
  - 45%~55% → 观望

  但旧版评估很粗糙——它的"置信度"只是 |prob - 0.5| × 200，不是真正的统计检验。想认真评估信号质量，应该用 v3
  的信号评估页。

  方式 3：使用「Alpha 评估器」代码直接跑

  layers/evaluation/alpha_eval.py 的 AlphaEvaluator 可以一键出完整报告：

  from layers.evaluation.alpha_eval import AlphaEvaluator

  alphas = AlphaEvaluator(predictions, actual_returns)
  report = alphas.full_report()  # 返回 IC/RankIC/IC序列/换手率/分位数
  print(report)

  四、可信度判断速查表

  ┌──────────┬───────────┬───────────┬────────┬──────────────────────────┐
  │   场景   │    IC     │  RankIC   │ t-stat │           判断           │
  ├──────────┼───────────┼───────────┼────────┼──────────────────────────┤
  │ 优秀信号 │ > 0.05    │ > 0.05    │ > 3    │ 可以信赖，可用于实盘     │
  ├──────────┼───────────┼───────────┼────────┼──────────────────────────┤
  │ 可用信号 │ 0.03~0.05 │ 0.03~0.05 │ 2~3    │ 有预测能力，但需结合风控 │
  ├──────────┼───────────┼───────────┼────────┼──────────────────────────┤
  │ 弱信号   │ 0.01~0.03 │ 0.01~0.03 │ 1~2    │ 预测能力不足，建议观望   │
  ├──────────┼───────────┼───────────┼────────┼──────────────────────────┤
  │ 无效信号 │ < 0.01    │ < 0.01    │ < 1    │ 基本是噪声，不可用       │
  ├──────────┼───────────┼───────────┼────────┼──────────────────────────┤
  │ 反向信号 │ < 0       │ < 0       │ —      │ 预测方向反了，模型有问题 │
  └──────────┴───────────┴───────────┴────────┴──────────────────────────┘

  ---
  五、一句话总结

  ▎ 用页面 6 训练模型 → 页面 7 看 IC 和 RankIC → IC > 0.03 且 t-stat > 2 则可信

  目前你系统里最专业、最可靠的可信度判断手段就是 layers/evaluation/alpha_eval.py 提供的 IC/RankIC 体系。旧的
  predictor.py 和 advanced_predictor.py 的"置信度"只是概率偏离 0.5 的程度，不是统计检验，参考价值有限。
