# ADR-0005：把框架迁移与 RL 策略研究分开验收

- 日期：2026-09-08；状态：Proposed。
- 关联：[Spec C-02～05、FR-02/07/08](../superpowers/specs/2026-09-08-react-fastapi-design.md)、[Review](../reviews/2026-09-08-react-fastapi-review.md)。

## 背景

用户希望 RL 自主决定买入、卖出和仓位，截面多因子研究由另一项目负责。当前实现已经采用日线单资产目标仓位。新技术栈可以改善实验管理，却无法回答行情信息是否存在可利用规律、RL 是否优于透明策略或回测是否能推广。

如果框架迁移时同时改特征、奖励、交易规则与模型参数，结果差异就无法归因；旧测试通过也不能证明新策略合理。

## 提议决定

本轮保留现有算法配置规则、观察、奖励、成交时序、费用、基准、切分和验证选模语义，只添加可选事件/取消边界以及应用所需的轻量规则提取。取消属于未完成执行，不制造一个“训练成功”的检查点或完整 seed 汇总。

研究记录补充 purpose、研究问题、数据口径、配置快照和明确来源；结果显示风险、仓位、换手、费用及全部 seed。默认比较规则只判断可比条件，不据此声称风险已经匹配或统计显著。

多 seed 用于观察算法随机性，不视为多段独立市场；重放用于检查保存与加载，不重复计作独立样本。测试区间不参与选模，不提供按测试成绩自动推荐“最佳 seed”的产品功能。

本轮不实现滚动样本外、风险匹配基准、市场机制升级、跨资产迁移或自动研究搜索。这些是合理的后续研究议题，需要明确假设、失败标准和新验收，而不是随 UI 重构混入。

## 备选方案

| 方案 | 收益 | 未采用原因 |
|---|---|---|
| 同时升级算法和奖励 | 可能探索更有价值的策略 | 无法清楚隔离工程迁移与研究变化的影响 |
| 仅复刻 UI，不补研究说明 | 界面迁移最直接 | 容易把演示、历史回放和策略证据混淆 |
| 保留语义，补可追踪实验协议 | 可以对照行为并保留后续探索空间 | 本提案采用；短期不承诺策略收益改善 |

## 影响与代价

迁移的成败可用可复现路径和行为回归判断；现有模拟环境的局限也会继续存在。需求明确的“RL 自主决策”得到保留，但多资产、完整市场规则和实盘能力不会随新界面自动出现。

同一固定模型在相同依赖环境重放时要求 NAV 误差不超过 1e-8；不同操作系统重新训练不要求权重逐位相同。重新训练仍需确认真实梯度更新、合法切分和不依赖测试选模。

## 验证与重审条件

AC-02、AC-04、AC-08～11、AC-15 保护软件和研究语义。若用户选择新的研究假设或市场范围，另开 Spec 与 ADR，把研究变更与已迁移系统的技术验收分开记录。
